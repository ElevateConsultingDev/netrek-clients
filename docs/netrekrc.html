Configuring .netrekrc

Client configuration for the Netrek SDL2 Mac client (and COW-compatible clients). Full option list is in the Reference Manual §7; this page covers the settings that matter most for playing on sturgeon.elevateconsulting.dev.

Where it lives

The client reads a plain-text file named .netrekrc from your home directory:

~/.netrekrc

Each line is key: value. Lines starting with # are comments. Restart the client after editing.

Required for this server

SettingValueWhy
tryShortoff With short packets on, the client's variable-length packet parser can desync the receive stream on this server (you reach the team screen, then the galaxy freezes). Turning it off is required.

Connecting

server:    sturgeon.elevateconsulting.dev
port:      2592
name:      yourname
password:  yourpassword     # optional; for a registered pilot

You can also pass the server on the command line: -h sturgeon.elevateconsulting.dev -p 2592. Remember the server is IP-restricted — email dave@elevateconsulting.dev to be whitelisted first.

Sound

SettingValuesNotes
soundon / offMaster switch for effects and the startup intro music.
soundMusicon / offStartup intro / theme music only.
soundVolume0–128Master volume.

Galactic map & planets

Options that make target planets easier to read at a glance:

SettingValuesWhat it does
agriCAPSon / offDraw AGRI (fast army-growth) planet names in UPPERCASE on the galactic map.
agriColor1–3Color of AGRI names — 1=white, 2=yellow, 3=grey (else the planet's own color).
showArmy0–3Draw the army count next to planets you have info on — 0=off, 1=local map, 2=galactic, 3=both.
showgalactic0–4Galactic planet view: 0=owner color, 1=resource icons (army/repair/fuel overlays), 2=standard, 3=MOO, 4=rabbit-ears.
showINDon / offMark independent (unowned) planets with an X.

Weapons display

SettingValuesWhat it does
phaserShrink0–16Shortens your drawn phaser beam from the ship outward. 0=full length; higher values draw only the far end (e.g. 11 starts the beam ~70% out). Cosmetic.
theirPhaserShrink0–16Same, for enemy phasers.

Keymap & mouse

Remap keys and mouse buttons with keymap and buttonmap — a string of action / key pairs. Example (swap tractor and pressor onto t/g):

keymap:    tygT

Format: pairs of <newkey><action>. See Reference Manual §3 (Command Reference) for every action letter and the default bindings.

A working starter file

# ~/.netrekrc  — Netrek SDL2 on the Elevate STURGEON server
server:        sturgeon.elevateconsulting.dev
port:          2592
name:          guest

tryShort:      off      # REQUIRED for this server

sound:         on
soundMusic:    off       # effects yes, startup jingle no

agriCAPS:      on
agriColor:     2         # yellow
showArmy:      3         # army counts on both maps
showgalactic:  1         # resource icons on the galactic
phaserShrink:  0         # full-length phaser beams

Something wrong? Tell us

If a setting doesn't behave the way this page says on the Mac client, that's a bug we want to hear about. See how to report it — include your .netrekrc, what you expected, and what happened.
